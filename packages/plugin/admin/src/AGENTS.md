# Admin changes

Read the root guide. Use Strapi's installed Design System and Content Manager APIs.
Keep UI text in translation files. Use the shared diagnostic objects in notices.
Hide unauthorized actions and retain server enforcement. Never accept an API key
from a settings response or put server configuration into the browser bundle.

Prefer data hooks, derived state and event handlers. Effects only synchronize an
external system. Every screen has explicit loading, empty and failure behavior.
Check keyboard use, focus return, labels and actual edit/list view interactions.
