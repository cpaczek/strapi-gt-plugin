# Documentation changes

Read the root guide and writing-style.md. Put installation before marketing copy.
Use only commands actually exercised and screenshots of the running application.
Describe measured compatibility and known limitations. The plugin is a community
integration. Do not invent an official affiliation, badge, remote or release.

Working research, plans, reviews and provenance stay in ignored .work. Write
original project-specific explanations. Check docs, UI text and commit messages.
